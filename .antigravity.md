# DaBot - Project Instructions & Developer Guide (`.antigravity.md`)

This file contains architecture details, environment instructions, conventions, and guidelines for AI agents and developers working on the **DaBot** codebase.

---

## 1. Project Overview

**DaBot** is a high-performance Python Discord music bot built on `discord.py` (v2.x) and `yt-dlp`. It provides resilient audio streaming, multi-channel voice isolation, prefetching for zero-gap playback, intelligent timestamp seeking, interactive playlist/search UI, and automated audio normalization.

### Core Files

| File | Purpose |
| :--- | :--- |
| `music_bot.py` | **Primary Entrypoint & Core Implementation**: Multi-channel player, caching, queue management, FFmpeg filters, UI views, and slash/prefix command handlers. |
| `start_bot.sh` | Shell script configuring environment variables (`PYTHONPATH`, `DISCORD_TOKEN`) and starting `music_bot.py`. |
| `cli_to_api.py` | Utility script translating CLI options for `yt-dlp` into Python API option dictionaries. |
| `test/` | Unit test suite covering caching, queue logic, timestamp parsing, and search prefix resolution. |
| `requirements.txt` | Core project dependencies. |
| `cookies.txt` | Optional YouTube cookies for bypassing age restrictions / bot detection (ignored by Git). |

## 2. Environment & Execution Runbook

### Environment Setup

The repository uses a Python 3.12 virtual environment located in `./venv`.

> [!IMPORTANT]
> When executing Python scripts or tests, ensure `PYTHONPATH` includes the workspace root and the virtual environment site-packages:
> ```bash
> export PYTHONPATH=".:./venv/lib/python3.12/site-packages"
> ```

### Running Unit Tests

Run all unit tests with the standard Python `unittest` test runner:

```bash
PYTHONPATH=".:./venv/lib/python3.12/site-packages" python3 -m unittest discover -s test
```

To run a single test module:

```bash
# Test cache expiration and LRU behavior
PYTHONPATH=".:./venv/lib/python3.12/site-packages" python3 -m unittest test/test_cache.py

# Test queue ordering and multi-channel isolation
PYTHONPATH=".:./venv/lib/python3.12/site-packages" python3 -m unittest test/test_music_queue.py

# Test timestamp parsing
PYTHONPATH=".:./venv/lib/python3.12/site-packages" python3 -m unittest test/test_timestamp_parser.py

# Test URL detection and prefix search logic
PYTHONPATH=".:./venv/lib/python3.12/site-packages" python3 -m unittest test/test_url_prefix.py
```

### Running the Bot

To start the bot using the startup script:

```bash
bash start_bot.sh
```

Or run directly with environment variables:

```bash
export DISCORD_TOKEN="YOUR_BOT_TOKEN"
PYTHONPATH=".:./venv/lib/python3.12/site-packages" python3 music_bot.py
```

For simultaneous multi-channel playback across voice channels in the same guild, specify secondary worker bot tokens:
```bash
export DISCORD_TOKENS="TOKEN_1,TOKEN_2,TOKEN_3"
# or DISCORD_TOKEN="TOKEN_1" DISCORD_TOKEN_2="TOKEN_2"
PYTHONPATH=".:./venv/lib/python3.12/site-packages" python3 music_bot.py
```

## 3. Architecture & Key Components (`music_bot.py`)

### 1. `FastInfoCache` (Dual-TTL In-Memory LRU Cache)
- **Metadata TTL**: 12 hours (43,200s) for video titles, webpage URLs, durations.
- **Stream URL TTL**: 4 hours (14,400s) for direct signed `googlevideo.com` CDN URLs (avoids 403 HTTP expiration errors).
- **Eviction**: Evicts oldest 10% when capacity reaches `max_entries` (default: 5,000).

### 2. `AudioTrack` (Data Structure)
- Dataclass encapsulating metadata: `title`, `webpage_url`, `stream_url`, `duration`, `modifier`, `timestamp`, `requester_name`, `requester_id`, `channel_id`.
- Helper `get_duration_str()` formats durations as `H:MM:SS` or `M:SS`.

### 3. `ChannelMusicPlayer` (Voice Channel Isolation)
- Each voice channel has its own isolated `collections.deque[AudioTrack]` queue.
- Concurrency locks:
  - `lock`: Protects queue mutations (`append`, `popleft`, `clear`, `shuffle`).
  - `play_lock`: Guards playback initialization and transitions.
- **Zero-gap prefetching (`prefetch_next`)**: Pre-resolves stream URLs for upcoming tracks in the background while the current track is playing.
- **Timestamp seeking (`seek_to`)**: Duplicates the current track with an updated timestamp offset and injects it at the head of the queue before stopping the voice client.

### 4. `MultiChannelMusicManager`
- Manages player instances indexed by `(guild_id, channel_id)`.
- Handles voice channel connection, channel moves (`vc.move_to(channel)`), and multi-bot worker distribution.

### 5. Audio Filtering & FFmpeg
- Uses `discord.FFmpegOpusAudio` with Opus streaming.
- **Dynamic Audio Normalization**: `dynaudnorm=f=150:g=15:p=0.95:m=10.0` prevents volume discrepancies across different YouTube uploads without audio pumping.
- **Modifiers**:
  - `nightcore`: `asetrate=44100*1.25,aresample=44100,atempo=1.25`
  - `vaporwave`: `asetrate=44100*0.8,aresample=44100,atempo=0.8`

### 6. Interactive Discord UI (`discord.ui`)
- `PlaylistConfirmView`: Interactive confirmation (`Queue All` vs `Cancel`) when a playlist contains >50 tracks.
- `SearchResultsView` / `SearchSelect`: Dropdown menu for interactive 5-result YouTube search (`!search <query>`).

| :--- | :--- | :--- |

| `!ytp <url/query>` | — | Play query with prefix `"ytp"`. |
| `!stp <url/query>` | — | Play query with prefix `"stp"`. |
| `!search <query>` | — | Interactive search returning top 5 YouTube results. |
| `!seekto <time>` | `!seek`, `!st` | Seek in current track (`HH:MM:SS`, `MM:SS`, or seconds). |
| `!pause` | — | Pause current playback. |
| `!resume` | — | Resume paused playback. |
| `!skip` | `!s` | Skip the current track. |

| `!shuffle` | `!sh` | Randomize the upcoming queue. |

## 5. Development Conventions & Guidelines

### Asynchronous Programming & Concurrency
- `discord.py` runs on an asyncio event loop. Never call blocking `yt_dlp` extraction directly on the loop.
- Use `safe_extract_info(...)` or run extraction in `executor` (`concurrent.futures.ThreadPoolExecutor`).
- In FFmpeg audio `after` callbacks (which run on separate OS threads), dispatch back to the main loop using:
  ```python
  asyncio.run_coroutine_threadsafe(delayed_next(), bot.loop)
  ```

### yt-dlp & Stream Stability
- YouTube CDNs enforce short expiration windows (~6h) and IP bindings on signed stream URLs. Never cache direct stream URLs long-term.
- `yt-dlp` extractor args configured for `['android', 'web']` to bypass common YouTube throttle patterns.
- If age-restriction or bot detection occurs, ensure `cookies.txt` is updated in the root directory.

### Testing New Features
- When modifying queue behavior, timestamp parsers, or cache policies, add or update corresponding unit tests in `test/`.
- Ensure all tests pass before committing:
  ```bash
  PYTHONPATH=".:./venv/lib/python3.12/site-packages" python3 -m unittest discover -s test
  ```

### Security & Secrets
- Never commit Discord bot tokens, OAuth tokens, or `cookies.txt` to version control.
- Ensure `.gitignore` continues to ignore `.env`, `cookies.txt`, `debug.log`, and `freeze.txt`.
